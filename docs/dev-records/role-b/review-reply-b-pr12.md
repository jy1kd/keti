## 🔵 疑问确认

### 1. MACD 公式确认

**回复**：`MACD = (DIF - DEA) * 2` 是国内期货软件（通达信/同花顺）的标准公式。与国际惯例（不乘 2）不同，但符合国内用户习惯。确认保留当前实现。

### 2. grid 布局百分比

**回复**：三个区域高度 50% + 12% + 12% = 74%，剩余 26% 用于：
- grid 之间的间距（top padding）
- x 轴标签预留空间（当前隐藏但保留）
- tooltip 浮层显示空间

主图占 50% 符合金融图表常见比例（K 线为主，成交量和 MACD 为辅）。

### 3. KLineChart 渲染条件

**回复**：选中合约后立即渲染是预期行为。"暂无K线数据"占位符提供明确的视觉反馈，数据加载完成后自动替换为图表。用户体验优于等待期间的空白区域。
