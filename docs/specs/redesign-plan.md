# 重构方案：多页面架构 + 虚拟滚动按需订阅

## 1. 概述

### 1.1 目标

将现有单页面三栏布局重构为标签页系统，实现类似专业交易终端（无限易、文华财经）的多页面体验。同时重构行情表格，支持全量合约显示 + 虚拟滚动按需订阅。

### 1.2 核心改动

| 改动 | 说明 |
|------|------|
| **标签页系统** | 顶部标签栏 + 内容区域，支持多标签切换 |
| **行情表格重构** | 全量合约（~6000+）+ 虚拟滚动 + 按需订阅 |
| **Electron 独立窗口** | 标签页可分离为独立窗口 |

## 2. 标签页系统设计

### 2.1 标签页类型

| 类型 | 图标 | 默认打开 | 可关闭 | 说明 |
|------|------|----------|--------|------|
| `market` | 📊 | ✅ | ❌ | 全量行情表格 |
| `favorites` | ⭐ | ❌ | ✅ | 自选合约（可选打开/关闭） |
| `order` | 📝 | ❌ | ✅ | 报单面板 |
| `query` | 📋 | ❌ | ✅ | 查询面板（报单/成交/持仓/资金） |
| `kline` | 📈 | ❌ | ✅ | K 线图 |
| `options` | 📉 | ❌ | ✅ | 期权 T 型报价 |

**标签页限制**：最多 15 个标签（含固定标签）

**固定标签**：`market`（行情）始终存在，不可关闭

### 2.2 标签页 Store

```typescript
type TabType = 'market' | 'favorites' | 'order' | 'query' | 'kline' | 'options';

interface Tab {
  id: string;                    // 唯一标识，如 "order-IF2608"
  type: TabType;                 // 标签类型
  title: string;                 // 显示标题
  props?: Record<string, any>;   // 附加参数（如 { instrumentID: 'IF2608' }）
  closable: boolean;             // 是否可关闭
}

interface TabStore {
  tabs: Tab[];
  activeTabId: string;

  // Actions
  openTab(type: TabType, props?: Record<string, any>): void;
  closeTab(tabId: string): void;
  setActiveTab(tabId: string): void;
  canOpenMore(): boolean;
  
  // 固定标签
  getFixedTabs(): Tab[];
  getDynamicTabs(): Tab[];
}
```

### 2.3 自选合约标签

自选合约标签（`favorites`）是**独立标签页**，点击后**新打开**一个标签页：

- **默认状态**：不打开
- **打开方式**：
  - 点击行情表格顶部的 [⭐ 自选] 按钮
  - 快捷键 `Ctrl+F`
  - 托盘菜单 "自选合约"
- **关闭方式**：点击标签的关闭按钮
- **数据来源**：`userPrefs.selectedContracts`（localStorage 持久化）
- **订阅策略**：始终订阅（不受虚拟滚动影响）

**与行情标签的关系**：
- 行情标签（📊 全量合约）和自选标签（⭐ 自选）**同时存在**
- 可以在两个标签之间切换
- 自选标签关闭后，行情标签保持不变

### 2.4 标签页操作

| 操作 | 说明 |
|------|------|
| **打开新标签** | 点击 "+" 按钮，选择标签类型 |

| **关闭标签** | 点击标签的关闭按钮，或中键点击 |
| **分离窗口**（Electron） | 右键标签 → "在新窗口打开" |
| **拖拽排序** | 拖拽标签调整顺序 |

### 2.5 标签页打开方式

## 3. 行情表格重构

### 3.1 数据源

| 数据 | 来源 | 说明 |
|------|------|------|
| **全量合约** | `instruments.json` | ~6000+ 合约，启动时加载 |
| **自选合约** | `userPrefs.selectedContracts` | localStorage 持久化 |
| **行情快照** | WebSocket 推送 | 只推送已订阅的合约 |

### 3.2 订阅策略

```
┌─────────────────────────────────────────────────────────────────────────────┐
│  全量行情表格                                                                │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │  合约      | 最新价 | 涨跌  | 买一   | 卖一   | 成交量 | 持仓量     │   │
│  │  ─────────────────────────────────────────────────────────────────  │   │
│  │  a2609     | 3580  | +5.0  | 3579.8 | 3580.2 | 1234  | 5678       │ ← 已订阅 │
│  │  ag2608    | 8150  | -20.0 | 8149   | 8151   | 5678  | 12345      │ ← 已订阅 │
│  │  al2608    | 20100 | +100  | 20098  | 20102  | 890   | 3456       │ ← 已订阅 │
│  │  ...                                                                │   │
│  │  au2608    | --    | --    | --     | --     | --    | --         │ ← 未订阅 │
│  │  bu2608    | --    | --    | --     | --     | --    | --         │ ← 未订阅 │
│  │  ...                                                                │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│  ════════════════════════════════════════════════════════════════════════   │
│  [====================] 滚动条                                              │
│         ↑                                                                   │
│    只订阅这个区域的合约（~20-30个）                                          │
└─────────────────────────────────────────────────────────────────────────────┘
```

**订阅逻辑**：

1. **始终订阅（永不退订）**：
   - ⭐ 自选合约
   - 📝/📈 打开标签的合约（报单/K线窗口锁定）
2. **按需订阅**：当前可见区域的合约（~20-30 个）
3. **自动退订**：滚动出视野的合约（300ms 防抖），但自选合约和打开标签的合约除外

**CTP 限制**：最多 500 个订阅，当前策略远低于限制（~50 个）

**订阅计算公式**：
```
应该订阅 = 可见区域 + 自选合约 + 打开标签的合约
需要退订 = 已订阅 - 应该订阅
```

### 3.3 未订阅合约显示

未订阅的合约显示占位符：

| 字段 | 显示 |
|------|------|
| 合约代码 | 正常显示 |
| 最新价 | `--` |
| 涨跌 | `--` |
| 买一/卖一 | `--` |
| 成交量 | `--` |
| 持仓量 | `--` |

### 3.4 数据流

```
1. 启动时
   ├── 加载全量合约列表（instruments.json → ~6000+）
   ├── 加载自选合约（userPrefs.selectedContracts）
   ├── 订阅自选合约
   └── 订阅可见区域合约

2. 滚动时（300ms 防抖）
   ├── 计算新增可见合约 → 批量订阅
   └── 计算不再可见合约 → 批量退订（自选合约和打开标签的合约除外）

3. 打开标签时
   ├── 将合约添加到 openTabContracts
   └── 如果未订阅，立即订阅

4. 关闭标签时
   ├── 从 openTabContracts 移除合约
   └── 如果不在可见区域且不是自选合约，退订

5. 数据更新时
   ├── WebSocket 推送 market_data
   ├── 更新 snapshots Map
   └── vtable 自动重渲染可见行
```

### 3.5 锁定合约机制

**问题**：用户打开某个合约的 K 线标签后，如果滚动行情表格导致该合约移出屏幕，系统会退订该合约，导致 K 线标签收不到数据更新。

**解决方案**：锁定合约机制

```
┌─────────────────────────────────────────────────────────────────────────────┐
│  锁定合约机制                                                                │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  锁定条件（满足任一即锁定）：                                                │
│  ├── ⭐ 自选合约                                                            │
│  └── 📝/📈 打开标签的合约（报单/K线窗口）                                   │
│                                                                             │
│  锁定行为：                                                                  │
│  ├── 永不退订                                                                │
│  ├── 即使移出屏幕也保持订阅                                                │
│  └── 持续接收数据更新                                                      │
│                                                                             │
│  解锁条件：                                                                  │
│  ├── 取消自选                                                                │
│  └── 关闭标签                                                                │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

**订阅计算公式**：
```typescript
// 应该订阅的合约
const shouldSubscribe = new Set([
  ...visibleContracts,      // 可见区域
  ...favoriteContracts,     // 自选合约
  ...openTabContracts,      // 打开标签的合约
]);

// 需要退订的合约
const toUnsubscribe = [...currentlySubscribed].filter(
  id => !shouldSubscribe.has(id)
);
```

**示例场景**：
```
1. 用户打开 IF2608 的 K 线标签
   └── openTabContracts = {IF2608}

2. 用户滚动行情表格，IF2608 移出屏幕
   ├── visibleContracts = {au2608, ag2608, al2608, ...}
   ├── favoriteContracts = {IC2608}
   ├── openTabContracts = {IF2608}
   └── shouldSubscribe = {au2608, ag2608, al2608, IC2608, IF2608}

3. 结果
   ├── IF2608 保持订阅（锁定）
   ├── IC2608 保持订阅（自选）
   └── IH2608 退订（不在可见区域、不是自选、没有打开标签）
```

## 5. 搜索与收藏功能

### 5.1 表格内搜索

**位置**：表格顶部左侧

**功能**：
- 输入即搜索（300ms 防抖）
- 支持中文搜索（合约代码、合约名称、品种名称）
- 清空按钮（✕）
- 快捷键 `Ctrl+F` 聚焦搜索框

**搜索逻辑**：
```typescript
const results = contracts.filter(c =>
  c.instrumentID.toLowerCase().includes(query) ||
  c.instrumentName.toLowerCase().includes(query) ||
  getProductName(c.productID).toLowerCase().includes(query)
);
```

### 5.2 合约搜索模态框

**触发方式**：
- 点击搜索框右侧的 "🔍" 按钮
- 快捷键 `Ctrl+Shift+F`

**功能**：
- 按交易所/品种筛选合约
- 收藏/取消收藏操作

**按钮变更**：

| 原有按钮 | 新按钮 |
|----------|--------|
| 刷新全量合约 | ✅ 保留 |
| 刷新预设合约 | ❌ 移除 |
| 订阅 | → 收藏 |
| 退订 | → 取消收藏 |
| 已订阅 | → 已收藏 |

### 5.3 收藏功能（替代订阅/退订）

**收藏按钮**（每行最后一列）：

| 状态 | 图标 | 点击操作 |
|------|------|----------|
| **已收藏** | ⭐ | 点击取消收藏 |
| **未收藏** | ☆ | 点击收藏 |

**收藏与订阅的关系**：

| 场景 | 收藏状态 | 订阅状态 |
|------|----------|----------|
| 收藏 + 可见 | ⭐ | ✅ 订阅 |
| 收藏 + 不可见 | ⭐ | ✅ 订阅（始终订阅） |
| 未收藏 + 可见 | ☆ | ✅ 订阅（按需） |
| 未收藏 + 不可见 | ☆ | ❌ 未订阅 |

**收藏同步**：
- 从模态框收藏的合约，在自选标签页也能看到数据推送
- 收藏合约始终订阅，无论在哪个页面操作

## 6. 风险评估

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| **CTP 订阅限制** | 最多 500 个 | 只订阅可见行 + 自选合约（~50 个） |
| **订阅/退订延迟** | CTP 响应时间 | 批量操作 + 300ms 防抖 |
| **全量合约加载慢** | 6000+ 合约 | instruments.json 缓存 + 异步加载 |
| **标签页状态丢失** | 切换标签时数据丢失 | Zustand store 保持状态 |
| **滚动性能** | 6000+ 行 | vtable 虚拟滚动（已有） |
| **自选合约重复订阅** | 流浪滚动与自选重叠 | 去重逻辑（Set 操作） |
