# 重构方案：多页面架构 + 虚拟滚动按需订阅

## 1. 概述

### 1.1 目标

将现有单页面三栏布局重构为标签页系统，实现类似专业交易终端（无限易、文华财经）的多页面体验。同时重构行情表格，支持全量合约显示 + 虚拟滚动按需订阅。

### 1.2 核心改动

| 改动 | 说明 |
|------|------|
| **标签页系统** | 顶部标签栏 + 内容区域，支持多标签切换 |
| **行情表格重构** | 全量合约（~6000+）+ 虚拟滚动 + 按需订阅 |
| **Electron 独立窗口** | 标签页可分离为独立窗口 |

## 2. 标签页系统设计

### 2.1 标签页类型

| 类型 | 图标 | 默认打开 | 可关闭 | 说明 |
|------|------|----------|--------|------|
| `market` | 📊 | ✅ | ❌ | 全量行情表格 |
| `favorites` | ⭐ | ❌ | ✅ | 自选合约（可选打开/关闭） |
| `order` | 📝 | ❌ | ✅ | 报单面板 |
| `query` | 📋 | ❌ | ✅ | 查询面板（报单/成交/持仓/资金） |
| `kline` | 📈 | ❌ | ✅ | K 线图 |
| `options` | 📉 | ❌ | ✅ | 期权 T 型报价 |

**标签页限制**：最多 15 个标签（含固定标签）

**固定标签**：`market`（行情）始终存在，不可关闭

### 2.2 标签页 Store

```typescript
type TabType = 'market' | 'favorites' | 'order' | 'query' | 'kline' | 'options';

interface Tab {
  id: string;                    // 唯一标识，如 "order-IF2608"
  type: TabType;                 // 标签类型
  title: string;                 // 显示标题
  props?: Record<string, any>;   // 附加参数（如 { instrumentID: 'IF2608' }）
  closable: boolean;             // 是否可关闭
}

interface TabStore {
  tabs: Tab[];
  activeTabId: string;

  // Actions
  openTab(type: TabType, props?: Record<string, any>): void;
  closeTab(tabId: string): void;
  setActiveTab(tabId: string): void;
  canOpenMore(): boolean;
  
  // 固定标签
  getFixedTabs(): Tab[];
  getDynamicTabs(): Tab[];
}
```

### 2.3 自选合约标签

自选合约标签（`favorites`）是**可选标签**：

- **默认状态**：不打开
- **打开方式**：
  - 点击标签栏的 "+" 按钮，选择 "自选合约"
  - 快捷键 `Ctrl+F`
  - 托盘菜单 "自选合约"
- **关闭方式**：点击标签的关闭按钮
- **数据来源**：`userPrefs.selectedContracts`（localStorage 持久化）
- **订阅策略**：始终订阅（不受虚拟滚动影响）

### 2.4 标签页操作

| 操作 | 说明 |
|------|------|
| **打开新标签** | 点击 "+" 按钮，选择标签类型 |
| **切换标签** | 点击标签，或使用快捷键 `Ctrl+1` ~ `Ctrl+9` |
| **关闭标签** | 点击标签的关闭按钮，或中键点击 |
| **分离窗口**（Electron） | 右键标签 → "在新窗口打开" |
| **拖拽排序** | 拖拽标签调整顺序 |

### 2.5 标签页打开方式

| 操作 | 结果 |
|------|------|
| **行情表格双击** | 打开该合约的报单标签 |
| **行情表格右键** | 菜单：打开报单 / 打开 K 线 |
| **自选合约双击** | 打开该合约的报单标签 |
| **自选合约右键** | 菜单：打开报单 / 打开 K 线 |
| **Ctrl+B** | 打开当前选中合约的报单标签 |
| **Ctrl+K** | 打开当前选中合约的 K 线标签 |
| **持仓列表"平仓"按钮** | 打开新报单标签 + 填充平仓参数 |
| **查询面板合约点击** | 仅选中该合约（不打开新标签） |

### 2.5 标签页快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+1` | 切换到行情标签 |
| `Ctrl+2` | 切换到自选标签（如果打开） |
| `Ctrl+3` | 切换到报单标签（如果打开） |
| `Ctrl+4` | 切换到查询标签（如果打开） |
| `Ctrl+5` | 切换到 K 线标签（如果打开） |
| `Ctrl+T` | 打开新标签 |
| `Ctrl+W` | 关闭当前标签 |
| `Ctrl+F` | 打开/关闭自选合约标签 |

## 3. 行情表格重构

### 3.1 数据源

| 数据 | 来源 | 说明 |
|------|------|------|
| **全量合约** | `instruments.json` | ~6000+ 合约，启动时加载 |
| **自选合约** | `userPrefs.selectedContracts` | localStorage 持久化 |
| **行情快照** | WebSocket 推送 | 只推送已订阅的合约 |

### 3.2 订阅策略

```
┌─────────────────────────────────────────────────────────────────────────────┐
│  全量行情表格                                                                │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │  合约      | 最新价 | 涨跌  | 买一   | 卖一   | 成交量 | 持仓量     │   │
│  │  ─────────────────────────────────────────────────────────────────  │   │
│  │  a2609     | 3580  | +5.0  | 3579.8 | 3580.2 | 1234  | 5678       │ ← 已订阅 │
│  │  ag2608    | 8150  | -20.0 | 8149   | 8151   | 5678  | 12345      │ ← 已订阅 │
│  │  al2608    | 20100 | +100  | 20098  | 20102  | 890   | 3456       │ ← 已订阅 │
│  │  ...                                                                │   │
│  │  au2608    | --    | --    | --     | --     | --    | --         │ ← 未订阅 │
│  │  bu2608    | --    | --    | --     | --     | --    | --         │ ← 未订阅 │
│  │  ...                                                                │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│  ════════════════════════════════════════════════════════════════════════   │
│  [====================] 滚动条                                              │
│         ↑                                                                   │
│    只订阅这个区域的合约（~20-30个）                                          │
└─────────────────────────────────────────────────────────────────────────────┘
```

**订阅逻辑**：

1. **始终订阅**：自选合约（不受滚动影响）
2. **按需订阅**：当前可见区域的合约（~20-30 个）
3. **自动退订**：滚动出视野的合约（300ms 防抖）

**CTP 限制**：最多 500 个订阅，当前策略远低于限制（~50 个）

### 3.3 未订阅合约显示

未订阅的合约显示占位符：

| 字段 | 显示 |
|------|------|
| 合约代码 | 正常显示 |
| 最新价 | `--` |
| 涨跌 | `--` |
| 买一/卖一 | `--` |
| 成交量 | `--` |
| 持仓量 | `--` |

### 3.4 数据流

```
1. 启动时
   ├── 加载全量合约列表（instruments.json → ~6000+）
   ├── 加载自选合约（userPrefs.selectedContracts）
   ├── 订阅自选合约
   └── 订阅可见区域合约

2. 滚动时（300ms 防抖）
   ├── 计算新增可见合约 → 批量订阅
   └── 计算不再可见合约 → 批量退订（自选合约除外）

3. 数据更新时
   ├── WebSocket 推送 market_data
   ├── 更新 snapshots Map
   └── vtable 自动重渲染可见行
```

## 6. 风险评估

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| **CTP 订阅限制** | 最多 500 个 | 只订阅可见行 + 自选合约（~50 个） |
| **订阅/退订延迟** | CTP 响应时间 | 批量操作 + 300ms 防抖 |
| **全量合约加载慢** | 6000+ 合约 | instruments.json 缓存 + 异步加载 |
| **标签页状态丢失** | 切换标签时数据丢失 | Zustand store 保持状态 |
| **滚动性能** | 6000+ 行 | vtable 虚拟滚动（已有） |
| **自选合约重复订阅** | 流浪滚动与自选重叠 | 去重逻辑（Set 操作） |
