## V1. 行情页工具栏单行，顶部 chrome 3 行，无「行情面板」标题

**前置条件：** 启动前端 `cd frontend && npm run dev`（http://localhost:5173），默认「行情」标签页，不依赖后端（无行情数据不影响布局验证）。

**验证步骤：**
1. 打开行情标签页，观察内容区顶部。
2. 确认顶部为「状态栏 + 标签栏 + 行情工具栏」3 行，之后紧跟行情表列头。
3. 确认行情工具栏为**单行**：左端「行情 | T型期权」segmented，中间搜索框 + 🔍 高级按钮，右侧「全部 | 自选」+「显示全部」+「收藏」。
4. 确认不存在「行情面板」标题文字。

**判断标准：** ✅ 工具栏单行无标题，顶部 3 行 chrome / ❌ 有异常堆叠或残留标题

**结果：** ✅ 通过 — 人工确认工具栏单行、顶部 3 行 chrome、无「行情面板」标题（2026-08-07）

## V5. K线页无 24px 拖拽条，标题栏 hover cursor 提示，title 在合约信息区

**前置条件：** 行情标签页选中一个合约，打开其 K 线标签页（双击行情行或右键→打开K线）。

**验证步骤：**
1. 打开 K 线标签页，确认顶部无「📈 拖动此栏可转弹窗」24px 拖拽条，内容直接是 K 线标题栏（合约代码/名称/最新价 + 周期 + 指标）。
2. 悬停 K 线标题栏的合约信息区（合约代码/名称处），确认光标变为可拖 grab 手势，且出现 title 提示「拖动此栏可将标签转为弹窗」。
3. 悬停周期按钮（1m/5m…）与指标下拉（MA/BOLL 等），确认**不**出现「拖动此栏」tooltip，光标为普通 pointer，点击周期/指标正常切换。

**判断标准：** ✅ 拖拽条已删、合约信息区有可拖提示、控件区无误导 tooltip / ❌ 任一不符

**结果：** ✅ 通过 — K线页拖拽条已删，合约信息区 grab cursor + title 提示，控件区无误导 tooltip（2026-08-07）
