## 逐条验证

### V1：点击平仓按钮能打开新报单标签
**前置条件：** 后端连接 SimNow、账户存在持仓、前端运行于 `feature/redesign-r20-position-close`
**验证步骤：** TabBar「📋 查询」打开弹窗 → 「持仓」子页 → 点击「平仓」→ 观察主界面
**预期表现：** 打开新报单标签并激活，标题 `📝 报单-{合约}`，查询弹窗仍浮于其上；重复点击去重激活已有标签
**结果：** ✅ 通过
**业务讨论：** 平仓后报单标签自动激活，参数随 orderForm 同步，与查询弹窗共存的悬浮交互符合 R15 弹窗化设计。

### V2：平仓参数填充正确
**前置条件：** 同 V1
**验证步骤：** 平仓打开报单标签后查看 OrderForm 各字段
**预期表现：** 合约=持仓合约；方向=平多→卖出/平空→买入；开平=今仓→平今/昨仓→平仓；数量=持仓数量
**结果：** ✅ 通过
**业务讨论：** OrderPage 挂载仅合并 instrumentID，不清空平仓参数（`setOrderForm` 合并语义），预填完整。

### V3：对手价获取正确
**前置条件：** 行情快照有该合约买卖盘
**验证步骤：** 平仓打开报单标签后查看价格字段
**预期表现：** 平多→卖一价 askPrice1；平空→买一价 bidPrice1；无快照时 limitPrice=0
**结果：** ✅ 通过
**业务讨论：** 对手价取自 snapshots 实时快照，与持仓方向对应（多→卖、空→买），行情缺失时回退 lastPrice。

### V4：标签页标题显示 `📝 报单-{ID}`
**验证步骤：** 平仓打开标签后查看 TabBar
**预期表现：** 标题 `📝 报单-{instrumentID}`
**结果：** ✅ 通过

### V5：今/昨仓区分
**验证步骤：** 分别对今仓/昨仓持仓点击平仓
**预期表现：** 今仓（todayPosition>0）→ 平今 close_today；纯昨仓 → 平仓 close
**结果：** ✅ 通过
**业务讨论：** 上期所/能源所今仓需平今，逻辑在 `onClose` 中按 todayPosition 判定。

### V6：重复点击平仓 → 标签去重激活 + 参数更新
**验证步骤：** 同一合约已开报单标签后再次平仓
**预期表现：** 不新开标签，激活已有标签；orderForm 响应式更新为最新平仓参数
**结果：** ✅ 通过
**业务讨论：** `openTab` 按 `tab-order-{ID}` 去重（`stores/tabs.ts`），已开标签时仅激活；参数经 zustand 订阅实时同步。
